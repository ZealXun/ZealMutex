# ZealMutex

ZealMutex 是一个面向 Android 10（API 29）及以上系统的本地应用限制工具。项目使用 Java、XML/原生 View 和 Android 系统 API，不依赖 AndroidX、Compose、数据库或网络框架，以尽量缩小 APK。

## 已实现功能

- 从所有带桌面入口的应用中选择限制对象（包括厂商预装普通应用），按包名保存规则；目标应用卸载重装不会重置规则和当天计时。
- 每个应用独立选择一种模式：每日累计时长，或按星期配置多个允许时段。
- 达到每日额度或允许时段结束后，立即显示 ZealMutex 全屏锁定层。
- 每个应用可设置一个累计使用时间循环提醒、自定义提醒词和独立展示模式：5 秒可滑动弹窗，或嵌入自定义图片且必须点击关闭的整页提醒。
- 每个应用可设置每天 0～5 次临时解锁，每次固定 1～10 分钟；临时使用仍计入当天统计并允许超额。
- 首次规则当天立即生效。已有规则的提醒间隔、文案、展示模式、图片和锁定页文字立即生效；使用额度、允许时段、临时解锁和删除到第二天 00:00 生效；待删除规则可在当天撤销。
- 每天 00:00 重置额度、提醒状态和临时解锁次数。
- 统计分屏、小窗和系统可识别的画中画窗口。
- 本周详细记录按天显示；每周一生成上一自然周的应用内报告并删除原始明细；报告由用户手动删除。
- 首页右上角提供“关于与更新”入口，在应用内查看当前版本、更新日志、生效规则、兼容范围和隐私说明。
- 自动识别手机厂商品牌并尝试打开对应后台管理入口；支持开机恢复、低打扰前台通知、使用情况记录补齐，网络校时失败时自动回退到手机本地时间。
- 电话、短信、系统设置、系统界面、桌面和 ZealMutex 自身强制加入安全白名单。

## 工程结构

- `app/src/main/java/com/zealmutex/app/data`：规则、每日记录、待生效变更和周报持久化。
- `app/src/main/java/com/zealmutex/app/engine`：时间校准、系统用量读取、安全白名单和规则判定。
- `app/src/main/java/com/zealmutex/app/service`：前台维护服务、开机恢复、无障碍监测、锁定层和通知。
- `app/src/main/java/com/zealmutex/app/ui`：权限引导、应用选择、规则编辑和报告页面。
- `assets`：原始设计图标；Android 使用的压缩资源位于 `app/src/main/res/drawable-nodpi`。

## 构建

需要 JDK 17 和 Android SDK。配置好环境后运行：

```sh
./build-apk.sh
```

未配置正式签名时，脚本会生成可安装的 debug APK：

```text
app/build/outputs/apk/debug/app-debug.apk
```

发展版的包名是 `com.zealmutex.app.dev`，应用名称为“ZealMutex Dev”，版本号带
`-dev` 后缀。它可以与正式发行版同时安装，规则和统计数据互不影响。

维护者发布正式版本时，将 `keystore.properties.example` 复制为
`keystore.properties` 并填写外部签名密钥信息。真实密钥和密码已被 Git
忽略，不应提交到仓库。此时脚本会生成经过 R8 压缩和资源收缩的签名 APK：

```text
app/build/outputs/apk/release/app-release.apk
```

## 分支与发布

- `main`：只接收经过验证、准备发行的稳定代码。
- `develop`：日常开发与功能集成分支。
- 功能开发使用 `feature/功能名` 分支，并合并到 `develop`。
- 正式版本从 `develop` 合并到 `main`，以 `v版本号` 创建标签，并通过
  GitHub Releases 发布签名 APK 和更新日志。

## 首次安装

1. 安装 APK；Android 13 及以上侧载时，如无障碍开关被限制，进入“应用信息 → 右上角菜单 → 允许受限设置”。
2. 打开 ZealMutex，应用会直接进入首页。
3. 按首页顺序开启使用情况访问、无障碍服务、通知和忽略电池优化，并按手机厂商的后台管理或应用启动管理完成设置。
4. 选择应用并创建第一条规则。每日时长模式会读取该应用从当天 00:00 起已经使用的时间。

## 隐私与系统限制

规则、应用列表、每日记录和周报只保存在应用私有存储中。整页提醒图片通过系统文件选择器读取用户单独选中的图片，不申请整个相册权限。联网仅通过 HTTPS 响应头校准当前时间，不上传使用记录。普通 APK 无法阻止用户强制停止、关闭权限或卸载 ZealMutex；卸载后应用也无法继续发出提醒。厂商后台管理开关通常没有公开的状态查询接口，ZealMutex 会识别品牌并打开设置入口，但仍需通过实际运行验证。
